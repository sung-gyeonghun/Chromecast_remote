- 빌드: assembleDebug / testDebugUnitTest / lintDebug 성공, 단위 테스트 5개 통과
- Lint: 오류 0개, 경고 10개. apksigner verify 통과.

## 연결과 검색

- Android 10 / Android 16 에뮬레이터에서 Google Cast NSD 서비스를 실제 Android NSD API로 등록·검색하는 계측 테스트 통과(각 1개).
- Remote v2 / Cast / 구형 Remote mDNS, DIAL SSDP 및 저장 IP 재확인 경로 구현. 실제 공유기 멀티캐스트 환경은 추가 확인 필요.
- 로컬 TLS 서버의 30초 간격 핑에도 연결 유지. 기존 16초 읽기 제한 제거 확인.
- 홈 전환 및 Activity 종료 이후에도 포그라운드 서비스가 연결 유지.
- 서버가 연결을 강제로 종료한 뒤 자동 재접속 확인.
- 앱의 연결 해제 후 재실행해도 해제 상태 유지. TLS close를 UI 스레드 밖으로 옮겨 종료 시 예외 수정.

## 볼륨과 화면

- Android 10 / 16에서 볼륨 키 down/up 송신 및 Cast GET_STATUS / SET_VOLUME 테스트 서버 검증.
- 감소: 0.50 → 0.45, 음소거: false → true, 증가: 0.45 → 0.50 및 음소거 해제 확인.
- 키보드 버튼과 IME 기능 제거. 메인 화면 17개 컨트롤이 스크롤 없이 화면 내부에 표시됨.
- 최종 APK 업데이트 설치, 라이트·다크 화면 캡처 및 육안 확인.

## 실제 기기 확인 범위

이 기록은 에뮬레이터와 로컬 테스트 서버 검증이다. v0.6.0의 실제 Chromecast 4세대 및 사용자의 공유기 환경에서 추가 확인이 필요하다. TV가 IR 전용 또는 고정 볼륨이면 Wi-Fi 명령으로 TV 음량을 변경할 수 없으며 볼륨 제어 설정을 확인해야 한다. 네트워크 장애·기기 전원 종료·앱 강제 종료 중 실제 접속은 보장할 수 없으며, 일시적인 통신 장애에는 시간 제한 없이 재접속을 시도한다.
