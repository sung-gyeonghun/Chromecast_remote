## 변경 및 확인

- 메인 화면의 `YOUR TV, IN YOUR HAND` 및 `리모콘` 제목 제거
- 좌측 상단에 빨간 벡터 전원 아이콘 배치, 접근성 이름 `전원 전환` 유지
- 하단 전원 버튼 제거, 기존 전원 명령 KEYCODE_POWER(26) 유지
- 기존 기기 설명, 물음표와 테마 토글 유지
- 기본 화면 및 360×640 dp 화면에서 컨트롤 18개가 스크롤 없이 표시되는 것 확인
- 제목과 영문 문구가 없고 전원 컨트롤이 한 개만 존재하는 것 확인
- 새 전원 아이콘을 눌러 로컬 TLS 테스트 서버에서 `KEY=26` 수신 확인
- 라이트/다크 및 키보드 미리보기를 새 버전으로 교체

실제 TV 전원 상태 변화는 이 테스트 서버 검사에 포함되지 않습니다. 기존과 같이 Chromecast 및 TV의 HDMI-CEC 설정에 따라 동작합니다.
